# 从实验脚本迁移

历史工程使用本地 Codex CLI 调用 Astra，并把 Inspire 实例、共享目录与部分场景验收条件写在脚本中。本项目将其分离为可安装的控制端、严格的阶段数据契约和固定的原生工作器。

| 旧行为 | 当前行为 |
|---|---|
| Codex 登录和 CLI 推理 | 官方 OpenAI API，环境变量密钥 |
| 固定 Astra 型号 | 可配置生成模型与审阅模型 |
| 一轮疑点补帧 | 有上限的补帧循环，未解决即停止 |
| 审阅历史总数 | 同一版本连续审阅通过 |
| 路径和实例写在脚本里 | TOML 配置，在 GPU 主机本地运行 |
| 多处断言和隐式 JSON 格式 | Pydantic 结构和显式跨字段校验 |
| 历史视频/实验记录 | 单独保留；不作为新版运行证据 |

原生工作器来源和原文件哈希保存于 `src/video_real2sim/native/provenance.json`。移植改动包括共享设备锁配置、明确 EULA 接受、物理步计时、初态证据与连接状态恢复，以及代码格式化。每项改动需要独立验证。

装配保持/释放已接入显式验证计划，并沿用真实运动学支撑目标和物理/渲染一致性检查。历史杯盖表面接触/查询、扳手接口和球体落台检查已迁为可配置计划，移除固定资产名称、固定状态索引与内置斜面半径。控制端要求每个计划指定的测试点、目标与转向均有证据；不能将普通静置通过代替专用验证。新的 GPU 执行结果须查验证记录，不能从迁移完成推断通过。
