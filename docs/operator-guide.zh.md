# 操作与故障恢复

## 三种检查的含义

| 命令 | 使用资源 | 能证明什么 |
|---|---|---|
| `real2sim doctor` | CPU，本地环境 | 配置有效、凭据变量是否存在、解释器能否解析；不验证账号权限或 GPU |
| `real2sim api-smoke image.jpg --output runs/api-check` | 一次可能计费的官方 API 请求 | 当前模型能接收图像并返回结构化数据；不代表场景重建成功 |
| `real2sim native-smoke examples/box-proposal.json --output runs/native-check --record` | GPU 和 Isaac Sim | 固定编译器、物理检查及通过后的实际视频解码；没有模型或人工视觉批准 |

上述命令默认读取 `config.toml`，也可在子命令前传 `--config path.toml`。完整重建仍使用 README 中的 `prepare → run → approve → record` 流程。

`.env` 不是自动读取的。若选择把本地凭据放在 `.env`，在可信本机 shell 中执行 `set -a; source .env; set +a` 后再运行命令。不要将该文件上传到仿真主机；GPU 子进程不需要 API 密钥。不要把不可信文件当作 shell 配置加载。

## 原生诊断范围

| 验证计划字段 | 保留的检查 | 使用限制 |
|---|---|---|
| `rest_checks` | 实测积分时钟、刚体漂移、碰撞深度 | 要求物体真实有支撑；不能把持物快照当静置 |
| `sweeps` | 连续驱动关节、实测到达角度或位移 | 明确驱动模型；不是机器人执行 |
| `assembly_checks` | 支撑父体抬升/倾斜、逐连接保持和释放、物理与渲染变换一致 | 单一共同父体、所有目标连接启用；保持和扶正释放均要测 |
| `surface_checks` | 2 个平面点、6 个斜面点的接触，8 个独立原生表面查询 | 近似轴对称杯盖，显式两个斜面半径，已编译的 Cube/Cylinder/Mesh 可视几何 |
| `freefall_checks` | 指定球体零速下落、指定支撑的正接触冲量、逐步球面间隙 | 单一原生球碰撞器、静态轴对齐盒状支撑，不是抛接轨迹 |
| `interface_checks` | 两个转向的插入/退出、间隙、接触、被动目标实际旋转 | 外部持握六角工具，世界 Z 插入、局部 Z 转动，不验证螺纹/扭矩 |

所有诊断状态都必须标明静置检查或排除理由。如果整段视频都是持物/腾空快照，可以没有静置项，但必须有至少一种可执行的其他物理诊断。超出能力的必要检查写入 `additional_requirements`，流程停止待扩展。

`scripts/gpu_smoke_suite.py` 提供 box、surface、freefall、assembly、interface 五类迁移检查。它保留样例几何并选择少量状态，记录原始文件哈希与所选索引；不继承历史批准，也不代替完整视频验收。

## 失败后怎么继续

- **模型发现几何或视觉问题**：自动进入下一个几何版本，同版本连续通过次数重新从零计算，旧版本保留。
- **API 网络中断/结构解析失败**：查看对应 `calls/.../receipt.json`；可能已计费。只有确认愿意再次发起调用后，才使用 `--retry-uncertain`。不要手工改收据伪装成完成。
- **API 明确拒绝**：收据记录 HTTP 状态码，不保存敏感错误体。修正凭据/额度后重新运行；模型或配置改变则用新运行目录。
- **仿真崩溃、超时或遗留 running/starting**：检查 `job.json` 与 `stdout.log`，确认原工作进程已退出。当前版本有意不自动重投，也不提供覆盖旧收据的命令；修复运行环境后使用新输出目录。每个进程只终止自己启动的进程组，不按进程名全局杀进程。
- **场景、输入、原生代码或配置改变**：使用新运行目录重新审阅。旧候选、批准和缓存不可移用于新内容。
- **最终录制审阅不通过**：状态是 `recording_needs_attention`，不会生成成功交付。修复后应以新运行目录重走相应验收。

`delivery.json` 绑定场景、视频、录制审阅、候选与人工批准文件；后续恢复时再次校验文件哈希。这里的哈希用于检测意外变化，不是防篡改签名服务。

## 给导师共享

发送源码压缩包和验证说明即可；导师可以先在 CPU 上安装、运行测试和查看 10 个几何样例。实际视频、API 凭据、Inspire 账号和运行目录均不在共享包中。若另行共享数据集片段或历史输出，需要沿用其原授权和来源说明。

历史样例中保留的中文注释可能提及历史版本和已做检查，这些是原始记录内容；`examples/historical/manifest.json` 明确不迁移历史审批。新版是否通过，以新版测试收据为准。
