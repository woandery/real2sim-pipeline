# 验证记录

本记录区分 CPU 测试、实际 GPU 执行和真实 API 调用。历史工程的批准不迁移到本项目。

## 本地验证

- 57 项 pytest 测试通过，机器可读记录为 `checks/pytest.xml`。包含真实 OpenAI SDK + MockTransport 协议测试、证据帧引用、补帧在最终审阅中保留、同版本连续通过、物理失败不得被视觉判断覆盖、子进程超时/失败/缓存、源码变更、原生诊断反例和完整离线状态机。
- Ruff lint/format 与 Python 源码编译通过。
- 全新隔离 Python 3.12 环境从 wheel 安装成功；在源码目录外运行 CLI、验证示例和导入九个原生工作器文件成功；`pip check` 无依赖冲突。
- 原有 10 个场景的几何契约均通过，迁移差异和来源哈希保存在 `examples/historical/manifest.json`。这些样例中的历史文字说明不是新版批准。
- 真实抽屉视频 117 帧全部解码、采样 48 帧；已查看第 3 张时间线图。这是采样验证，不是新 API 重建效果验证。

## 实际 GPU 检查

2026-11-27，在已有 RTX 4090 实例、Isaac Sim 5.0.0 环境运行冻结工作器。验证脚本为 `scripts/gpu_smoke_suite.py`，五类检查使用独立目录；CPU 数值门槛由控制端检查，不依赖模型“通过”的判断。

| 检查 | 实际范围 | 原生执行结果 |
|---|---|---|
| 合成盒子 | 2 个状态静置、被动关节变体、连续开盖扫掠、8 秒录制 | 通过 |
| 球体落台 | 初始、高位、最终持物快照的 3 次零速释放；指定原生支撑、正接触、逐步间隙 | 通过 |
| 杯盖表面 | 一个保留杯盖的 2 个平面接触、6 个斜面接触、8 个原生查询 | 通过 |
| 装配 | 共同父体外部支撑，4 个连接的保持及扶正后独立释放 | 通过 |
| 六角工具接口 | 2 个目标各测正反两方向，共 4 次插入/转动/退出 | 通过 |

最终只读审计检查作业退出码、冻结原生源码哈希、全部登记输出哈希，并用当前控制端重新检查数值条件。结果见 `checks/gpu-validation.json`；原始详细日志和完整原生状态轨迹保留在独立验证目录。

**保留的失败记录**：第一次盒子编译与渲染成功后，物理工作器在 Kit 启动阶段发生原生崩溃（退出码 -11），没有被登记成成功。独立新尝试使用相同物理几何，将 OMP/OpenBLAS/MKL 线程数显式设为 4，完成以上五类检查。尚未确认首次崩溃根因；这不是“已修复所有 Kit 启动问题”的结论。

盒子原生录制共 192 帧、24 FPS，已完整解码并检查非空图像；已实际查看 0、48、95、96、144、191 帧，开合状态和视角变化可见。`checks/native-box-orbit.mp4` 是合成几何样例，不能用来声称真实视频重建质量或机器人执行成功。其他四类的通过范围是所列数值诊断，不代表对全部原视频的重新视觉批准。

## API 状态与限制

按项目所有者要求，API 密钥先留空，模型保留可配置占位符。**未发起真实 OpenAI API 调用**；模型权限、实际生成质量、完整 API 多轮流程的成本和耗时尚未验证。`real2sim api-smoke` 可在之后配置凭据时测试图像与结构化输出接口。

测试中的离线 API/仿真替身有明确标识，不能当成真实原生执行。当前不包含机器人 PPO 训练、精确轨迹恢复、材料标定、柔性纸板模拟或手部重建。
